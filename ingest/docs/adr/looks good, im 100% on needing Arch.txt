Quickstart with Docker
1
Build the Docker image

docker build -t mem0-mcp-server https://github.com/mem0ai/mem0-mcp.git
2
Run the container

docker run --rm -d \
  --name mem0-mcp \
  -e MEM0_API_KEY="m0-..." \
  -p 8080:8081 \
  mem0-mcp-server
3
Configure your client for HTTP

For clients that connect via HTTP (instead of stdio):
{
  "mcpServers": {
    "mem0-docker": {
      "command": "curl",
      "args": ["-X", "POST", "http://localhost:8080/mcp", "--data-binary", "@-"],
      "env": {
        "MEM0_API_KEY": "m0-..."
      }
    }
  }
}
4
Verify the setup

# Check container logs
docker logs mem0-mcp

# Test HTTP endpoint
curl http://localhost:8080/health
The container should start successfully and respond to HTTP requests. If port 8080 is occupied, change it with -p 8081:8081.

After the wizard creates your config (openclaw.jsonc), add/merge a block like this (adjust to taste). The docs show these knobs and the defaults/deny list behavior.

{
  agents: {
    defaults: {
      sandbox: {
        mode: "non-main",        // or "all" if you want max isolation
        scope: "agent",
        workspaceAccess: "rw",
        docker: {
          image: "openclaw-sandbox-common:bookworm-slim",
          network: "none",       // safer default; opt-in egress only when needed
          readOnlyRoot: false,   // only if you truly need setupCommand installs
          user: "0:0",           // only if using apt in setupCommand
          setupCommand: "apt-get update && apt-get install -y git curl jq"
        },
        browser: {
          enabled: true,
          image: "openclaw-sandbox-browser:bookworm-slim",
          headless: false
        },
        prune: {
          idleHours: 24,
          maxAgeDays: 7
        }
      }
    }
  },
  tools: {
    sandbox: {
      tools: {
        allow: [
          "exec", "process", "read", "write", "edit",
          "sessions_list", "sessions_history", "sessions_send", "sessions_spawn", "session_status",
          "browser"   // add this if you want browser in sandbox
        ],
        deny: ["canvas", "nodes", "cron", "discord", "gateway"]
      }
    }
  }
}

How to use it (no ceremony)
1) Copy /infra into your repo root

Unzip, then copy the infra/ folder into your repo root (replacing the wiped folder).

2) Create env
cp infra/env/nyra.env.example infra/env/nyra.env
# edit infra/env/nyra.env and set OPENROUTER_API_KEY
3) Stand up everything

WSL/Linux

bash infra/scripts/bootstrap.sh

Windows PowerShell

powershell -ExecutionPolicy Bypass -File .\infra\scripts\bootstrap.ps1
4) Verify

TwentyCRM: http://localhost:3000

n8n: http://localhost:5678

Activepieces: http://localhost:8080

LiteLLM: http://localhost:4000

Nexus (MCP): http://localhost:8000/mcp

Grafana: http://localhost:3001

OpenClaw / Clawdbot install (optional, included)

Once base infra is up:

bash infra/scripts/openclaw/install_openclaw_docker.sh
“Top 20 skills by downloads” (from ClawHub) — generated locally

Because the ClawHub downloads page is JS-rendered and not reliably extractable here, use:

bash infra/scripts/openclaw/skills_top20_downloads.sh

That writes:

infra/openclaw/top20_downloads.json
