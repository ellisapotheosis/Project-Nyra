4) Strict Rules / Non-Negotiables
Absolute rules

NO MetaMCP anywhere. Do not mention it, do not use it, do not route through it.

Grafbase/Nexus is the single entrypoint for:

MCP proxy aggregation

fuzzy tool selection (tool filtering to save tokens)

model/provider routing in tandem with LiteLLM

Docker Desktop on Windows + WSL2 backend is the runtime.

Do NOT assume Docker Engine installed inside WSL2.

Do NOT use systemd inside WSL as a dependency (treat as “no systemd in WSL”).

Workers are inference-only:

RTX5090 + RTX3090Ti: vLLM + LMCache + Redis

RTX3060: Ollama

Remove/avoid these components entirely:

Dify

Open-WebUI

LobeChat

mem0/openmemory mcp (unless explicitly reintroduced later)

OpenRouter (removed unless later reintroduced as cloud fallback)

Gitea uses Postgres (not sqlite).

Secrets management

Use Infisical agent + sidecar pattern for services that need secrets.

Avoid plaintext .env with real secrets committed or left around.

Testing + release discipline

No blind auto-merge to main.

Prefer confidence-weighted automerge: only auto-merge when:

tests pass

health checks pass

lint/format pass

diffs are scoped

rollback plan exists

Otherwise require manual approval.

Operational policies

No public database ports exposed to the internet.

All public HTTP access goes via Cloudflare tunnel (cloudflared) to curated services only.

Tailscale is required for internal service-to-service connectivity between Oracle + home LAN + workers.
