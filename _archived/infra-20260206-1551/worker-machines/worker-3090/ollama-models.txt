# ============================================================================
# Performance Tips
# ============================================================================

# 1. Use quantized models (q4_K_M, q5_K_M) if VRAM is limited
# 2. Offload layers to CPU if model doesn't fit in VRAM
# 3. Adjust OLLAMA_NUM_GPU environment variable
# 4. Use smaller context windows to reduce memory usage
# 5. Run multiple smaller models instead of one large model
# 6. Cache models in RAM for faster loading
