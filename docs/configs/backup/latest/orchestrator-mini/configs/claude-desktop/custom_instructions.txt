# Project Nyra - Custom Instructions for Claude Desktop

## Project Context
You are working on Project Nyra, a distributed mortgage processing platform with multi-agent AI orchestration.

## Architecture Overview
- **Monorepo Structure**: pnpm workspaces with Turborepo
- **Applications**: Next.js 14 (RateHunter, Nyra Admin, CRM)
- **Services**: Python FastAPI microservices (Quote API)
- **Infrastructure**: Docker Compose, multi-stage builds
- **AI Orchestration**: Claude Flow V3 with HNSW indexing, SONA neural architecture

## Key Technologies
- Frontend: Next.js 14, TypeScript, Tailwind CSS, shadcn/ui
- Backend: Python 3.11, FastAPI, Pydantic V2
- Database: PostgreSQL 15+, Supabase
- AI: Claude Flow V3, AgentDB, ReasoningBank
- Infrastructure: Docker, n8n workflows, Infisical secrets

## Development Guidelines

### 1. File Organization (CRITICAL)
- NEVER save working files to root directory
- Use proper subdirectories: /src, /tests, /docs, /config, /scripts, /examples
- Follow monorepo structure: apps/*, services/*, packages/*

### 2. Concurrent Operations (MANDATORY)
- ALL related operations in ONE message
- Batch TodoWrite calls (5-10+ todos minimum)
- Spawn agents concurrently with run_in_background: true
- No sequential checking or polling

### 3. Claude Flow V3 Integration
- Use CLI for coordination: npx @claude-flow/cli@latest
- Memory operations: store, search, retrieve patterns
- Hooks: pre-task, post-task, session management
- Background workers: optimize, audit, testgaps

### 4. Multi-Agent Orchestration
- Initialize swarm: hierarchical topology (anti-drift)
- Spawn agents: researcher, architect, coder, tester, reviewer
- Use Task tool with full instructions
- Wait for background results, then synthesize

### 5. Code Quality Standards
- TypeScript: strict mode, proper typing, no any
- Python: type hints, Pydantic models, async/await
- Testing: 80%+ coverage, unit + integration tests
- Security: input validation, no hardcoded secrets

### 6. Auto-Learning Protocol
- Search memory before starting tasks
- Store successful patterns after completion
- Use hooks for routing and optimization
- Train neural patterns on good code

### 7. Component-Specific Guidelines
- Consult component CLAUDE.md files for tech-stack details
- Follow framework-specific patterns (Next.js, FastAPI)
- Use appropriate agents for each task type
