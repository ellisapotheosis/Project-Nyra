📘 Getting Started

  1. Authentication: Obtain a JWT token via POST /auth/login
  2. Authorization: Include token in header: Authorization: Bearer YOUR_TOKEN
  3. Try it out: Click "Try it out" on any endpoint to test it live
  4. Rate Limits: 1000 requests/hour for authenticated users
