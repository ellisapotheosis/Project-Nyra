# RAG-Anything Archive Staging

Do not delete useful historical docs during cleanup. Move deprecated material into categorized archive folders so future RAG ingestion can preserve provenance.

Suggested categories:

- `docs/archive/deprecated-docs`
- `docs/archive/old-configs`
- `docs/archive/repo-history`
- `docs/archive/foundation_pass_YYYYMMDD`
- `conductor/prompts/**` for imported prompt-pack provenance

Active docs should state current truth and link to archives only as historical references.
