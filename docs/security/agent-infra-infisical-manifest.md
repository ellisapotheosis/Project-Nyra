# Agent Infra Infisical Manifest

This manifest covers the Oracle agent utilities, cognitive backend, Composio injection, and Kyutai voice mesh.

## Paths

| Path                      | Purpose                           |
| ------------------------- | --------------------------------- |
| `/clients/searxng`        | SearXNG secrets                   |
| `/clients/browserless`    | Browserless secrets               |
| `/clients/letta`          | Letta secrets                     |
| `/databases/qdrant-local` | Qdrant local database secrets     |
| `/providers/openai`       | OpenAI provider credentials       |
| `/providers/anthropic`    | Anthropic provider credentials    |
| `/providers/litellm`      | LiteLLM provider credentials      |
| `/clients/composio`       | Hosted Composio MCP configuration |

## Generated by Nyra

These are service-owned secrets. Generate with `scripts/infisical/agent-infra-secrets.sh generate`.

| Secret                  | Path                      |
| ----------------------- | ------------------------- |
| `SEARXNG_SECRET`        | `/clients/searxng`        |
| `BROWSERLESS_TOKEN`     | `/clients/browserless`    |
| `LETTA_DB_PASSWORD`     | `/clients/letta`          |
| `LETTA_SERVER_PASSWORD` | `/clients/letta`          |
| `QDRANT_API_KEY`        | `/databases/qdrant-local` |

## Retrieved from Local Environment When Present

| Secret                   | Path                   |
| ------------------------ | ---------------------- |

| `ANTHROPIC_API_KEY`      | `/providers/anthropic` |

| `COMPOSIO_MCP_URL`       | `/clients/composio`    |

## Config Stored Beside Secrets

These are not secret values, but storing them in Infisical keeps Compose rendering deterministic.

| Key                         | Path                |
| --------------------------- | ------------------- |
| `COMPOSIO_DEFAULT_USER_ID`  | `/clients/composio` |
| `COMPOSIO_MCP_TRANSPORT`    | `/clients/composio` |
| `COMPOSIO_MCP_SERVER_NAME`  | `/clients/composio` |
| `COMPOSIO_TOOLKITS_ALLOW`   | `/clients/composio` |
| `COMPOSIO_EXECUTION_POLICY` | `/clients/composio` |

## Commands

```bash
scripts/infisical/agent-infra-secrets.sh generate
scripts/infisical/agent-infra-secrets.sh audit
scripts/infisical/agent-infra-secrets.sh push
```

The generated local file is `secrets/infisical/agent-infra.generated.env`, which is ignored by git.
