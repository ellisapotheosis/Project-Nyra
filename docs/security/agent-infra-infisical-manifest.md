# Agent Infra Infisical Manifest

This manifest covers the Oracle agent utilities, cognitive backend, Composio injection, and Kyutai voice mesh.

## Paths

| Path | Purpose |
|---|---|
| `/oracle/agent-utils` | Paperclip, SearXNG, Browserless |
| `/oracle/memory` | Letta, mem0, FalkorDB, Qdrant |
| `/shared/providers` | Shared external LLM/provider credentials |
| `/shared/composio` | Hosted Composio MCP configuration |
| `/worker-rtx3060/voice` | Base Unmute and mesh ingress/VAD config |
| `/worker-rtx3090ti/voice` | Streaming STT and LLM bridge config |
| `/worker-rtx5090/voice` | Session coordinator, TTS, egress mux config |
