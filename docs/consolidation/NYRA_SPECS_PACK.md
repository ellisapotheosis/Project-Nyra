# Nyra Specs Pack

This specs pack summarises product requirements across the Project Nyra ecosystem. It is organised by product surface and draws from the official requirement documents.

## 1. RateHunter.net
RateHunter.net is the public mortgage lead generation platform for Project Nyra. It must function as a high‑conversion landing page and integrate seamlessly with backend campaign systems.

### Business Objectives
- **Lead capture:** Collect qualified mortgage leads 24/7 across multiple channels【556230783072290†L12-L16】.
- **Lead qualification:** Automatically classify leads (personal, commercial, residential)【556230783072290†L12-L16】.
- **Instant response:** Provide immediate engagement through automated systems【556230783072290†L17-L18】.
- **Conversion optimisation:** Guide leads through the inquiry process and maximise consultation bookings【556230783072290†L19-L29】.
- **Brand positioning:** Establish Ellis D Andersen LLC as a trusted mortgage advisor【556230783072290†L20-L22】.

### Key Feature Requirements
1. **Multi‑channel lead capture (FR‑001):** Support web forms, click‑to‑call, SMS capture, email forms, chatbot integration and missed‑call automation【556230783072290†L35-L49】. Progressive disclosure collects personal information, loan details, source details and consent flags; integrate with voice and SMS APIs and respect privacy & TCPA compliance.
2. **Real‑time quote generation (FR‑002):** Provide instant mortgage rate quotes based on lead inputs and integrate with a loan origination system (LOS)【556230783072290†L85-L100】. Show APR, monthly payment, total interest, product comparisons and generate PDF quotes delivered via email.
3. **Interactive mortgage calculator (FR‑003):** Allow visitors to explore scenarios before submitting information; support loan amount sliders, down payment selectors, term selectors, interest rate inputs, property tax estimators, PMI and amortisation visualisations【556230783072290†L115-L130】. Include a “Get This Rate” call‑to‑action that pre‑fills the lead form.
4. **Educational content hub (FR‑004):** Publish SEO‑optimised content to nurture leads through the buying journey and establish authority. Provide first‑time buyer guides, refinancing resources, commercial property financing topics and market updates with keyword targeting and schema markup【556230783072290†L141-L176】.
5. **Trust & social proof (FR‑005):** Display testimonials, reviews, licences and accreditation, lender logos, media mentions and dynamic counters to build credibility【556230783072290†L179-L190】.
6. **Nyra AI assistant integration (FR‑006):** Embed a floating chatbot powered by OpenClaw to greet visitors, answer mortgage questions, qualify leads through conversation and hand off to human agents when appropriate【556230783072290†L199-L211】. Support multilingual interactions.
7. **Mobile‑first responsive design (FR‑007):** Optimise for mobile and tablet viewports with touch‑friendly controls, simplified navigation, fast load times, offline calculator and one‑tap call/SMS actions【556230783072290†L233-L247】.
8. **Cloud‑tunnel integration (FR‑008):** Host the site behind a secure tunnel, enable DDoS protection, SSL/TLS, CDN caching, rate limiting and WAF rules. Provide DNS configuration for root and subdomains【556230783072290†L256-L276】.

### Success Metrics
- Lead capture rate >80 %; lead quality score >7.5/10; sub‑2‑minute response; >25 % conversion to consultation; mobile conversion parity close to desktop【556230783072290†L25-L29】.

## 2. Project Nyra Broker/Customer Webapp
This app serves as the central command hub for brokers and customers.

### Functional Requirements
- **Intake and status:** Allow borrowers to submit loan applications, upload documents and check loan status.
- **Quote views:** Display deterministic 3‑option quotes generated by the quote service; provide PDF downloads.
- **Document collection:** Support file uploads and secure storage.
- **Chat interface:** Integrate the OpenClaw assistant for questions and help.
- **Notifications:** Provide real‑time updates on lead status, quote availability and compliance events.

### Admin Portal
- **Dashboard:** Overview of active leads, campaign performance and compliance status【858937579590172†L168-L180】.
- **Lead management:** View and edit lead details; trigger ingestion workflows.
- **Campaign management:** Create and manage campaigns, schedules, quiet hours and STOP/subscribe logic.
- **Quote management:** Generate and manage quotes; enforce invariants that quotes originate from the quote service only【858937579590172†L152-L166】.
- **Communication timeline:** Log all communications and link them to CRM records.
- **Compliance controls:** Enforce consent and do‑not‑contact rules; audit logs for STOP/unsubscribe actions【858937579590172†L119-L134】.
- **Assistant tooling:** Provide operator tools for controlling and auditing assistant interactions.

### Acceptance Criteria
- Lead ingestion writes correct CRM records; campaign engine schedules and stops correctly; STOP/reply/unsubscribe rules operate immediately; quote engine produces deterministic scenarios; admin UI exposes operational controls; webapp integrates the assistant chat surface; all domain logic has tests【858937579590172†L207-L217】.

## 3. Backend Services
Implementation of backend services follows the execution plan and architecture guidelines.

- **CRM API:** Wraps Twenty CRM and enforces system-of-record ownership【263234951327427†L14-L16】.
- **Lead Ingestion Service:** Normalises payloads, deduplicates leads, writes cleaned records, assigns eligibility and logs audits【858937579590172†L87-L103】.
- **Campaign Service:** Manages campaign definitions, scheduling, pause/resume, reply-based pausing, STOP-based cancellation, quiet hours, per‑channel eligibility and enrollment state【858937579590172†L104-L116】.
- **Compliance Service:** Handles STOP/unsubscribe logic, do‑not‑contact enforcement, channel consent, quiet hours and suppression audits【858937579590172†L119-L129】.
- **Communication Service:** Sends and receives across email, SMS and voice; logs messages and synchronises with CRM【858937579590172†L136-L151】.
- **Quote Service:** Generates deterministic quotes, calculates payments and costs, produces PDFs and manages quote history and expiration【858937579590172†L152-L166】. Assistants must never fabricate quote terms.
- **Assistant Service:** Provides safe tool orchestration for assistant surfaces; ensures memory, tool calls and service mutations follow policy.
- **API Gateway:** Unifies API access across services and enforces rate limits and authentication.

## 4. Infrastructure & Ops
- **Deployment rules:** Use Docker Compose per node; runtime compose files live under `infra/hosts/<host>` and nowhere else【423519143471560†L4-L29】.
- **Validation:** Perform baseline checks (WSL updates, Docker, GPU drivers), confirm Tailscale connectivity and run health checks.
- **Node deployment:** Deploy Ollama on the utility worker, vLLM on the heavy workers, the control plane stack on the orchestrator and durable services on the cloud VPS【423519143471560†L18-L29】.
- **Model routing:** Configure model router such that heavy coding tasks prefer hosted LLMs (e.g., Claude) while local models handle large payloads and small tasks【423519143471560†L31-L36】.
- **Ingress policy:** Only expose necessary subdomains via the tunnel; keep databases and inference endpoints private; protect admin surfaces with access control【423519143471560†L38-L43】.

## 5. UI Standards & Design
- Use Next.js App Router, TypeScript, Tailwind, ShadCN/Magic UI and shared palette tokens across all applications【858937579590172†L196-L205】.
- Follow a dark mode palette (indigo/seafoam/neon‑pink), high professional density, strict component patterns and no light mode. Maintain consistent spacing, typography and component usage.
