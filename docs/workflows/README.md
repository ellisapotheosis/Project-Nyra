# Workflow Documentation

Workflow docs are split by automation runtime.

| Folder                           | Scope                                                                    |
| -------------------------------- | ------------------------------------------------------------------------ |
| [`n8n/`](n8n/)                   | Canonical location for n8n workflow JSON exports and n8n workflow notes. |
| [`activepieces/`](activepieces/) | Activepieces workflow notes.                                             |

Business rules still belong in Nyra services. n8n and Activepieces are execution glue, not the system of record or business brain.
