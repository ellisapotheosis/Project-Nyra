# INFISICAL_SECRETS_RUNBOOK.md

## Secret Hierarchy

Secrets are managed in Infisical and injected into services at runtime.

### 1. Global / Shared

- `INFISICAL_PROJECT_ID`
- `TAILSCALE_AUTHKEY`
- `CLOUDFLARE_TUNNEL_TOKEN`

### 2. Communication Providers

- `/providers/twilio/ACCOUNT_SID`
- `/providers/twilio/AUTH_TOKEN`
- `/providers/sendgrid/API_KEY`

### 3. LLM / AI

- `/providers/openrouter/API_KEY`
- `/providers/nexus/API_KEY`
- `/providers/litellm/MASTER_KEY`

### 4. Databases

- `/databases/postgres/PASSWORD`
- `/databases/redis/PASSWORD`
- `/databases/falkordb/PASSWORD`

## Usage in Development

Inject secrets into your local environment:

```bash
infisical run --env dev -- pnpm dev
```

## Usage in Docker

Services in `docker-compose.yml` should reference env files generated by Infisical or use the Infisical agent.

## Rotation Policy

- Rotate provider keys (Twilio, SendGrid) every 90 days.
- Rotate database passwords annually or upon personnel change.
- Never share real secrets via chat or document them in non-gitignored files.
