# Repo History Archive

This directory is the canonical location for all repository historical material.

## Structure

- `archive-root/`
Legacy content previously stored under the repo root `archive/`.
- `archived-root/`
Legacy content previously stored under the repo root `_archived/`.
- `scripts-archive/`
Legacy content previously stored under `scripts/_archive/`.

## Policy

- New archive operations must target `docs/archive/repo-history/archive-root/YYYYMMDD/...`.
- Do not recreate `archive/`, `_archived/`, or `scripts/_archive/` at repository root.
- Update `docs/archive/repo-history/archive-root/INDEX.md` for every archive move:

`old/path -> new/path`
