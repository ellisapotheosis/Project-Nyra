## 🚀 QUICK START (5 MINUTES)

### Prerequisites
- Docker Desktop (with Docker Compose)
- Node.js >=20
- npm >=10
- Cloudflare account (free tier OK)
- Tailscale (for worker mesh networking)

### Steps

**1. Initialize Project**
```bash
make init
```
✅ Creates directory structure, installs dependencies

**2. Bootstrap Everything**
```bash
make bootstrap
```
✅ Starts all services, initializes databases, runs health checks

**3. Discover Ports & Generate Tunnel Config**
```bash
make port-discovery
```
✅ Auto-discovers 12+ services, generates cloudflared config

**4. Setup & Start Tunnel**
```bash
make tunnel-setup
make tunnel-start
```
✅ Configures Cloudflare tunnel, exposes services to https://ratehunter.net

**5. Verify Everything Works**
```bash
make health-check
make verify-connectivity
```
✅ Comprehensive system verification

**Done!** 🎉 Your complete mortgage platform is running.

## 📊 INFRASTRUCTURE HOSTING DECISIONS

### Where Things Run

| Service | Hosted | Exposed | Why |
|---------|--------|---------|-----|
| **Orchestrator (Control Plane)** | PC1 (Minisforum) | Cloudflared | Always-on coordinator |
| **Nexus Router** | PC1 | nexus.ratehunter.net | MCP hub + LLM router |
| **Archon OS** | PC1 | Internal | Context and workflow coordination |
| **PostgreSQL, Redis, Qdrant** | PC1 | Internal (Tailscale) | Databases for all services |
| **GPU Workers (Inference)** | PC2/3/4 (Tailscale mesh) | Internal | Distributed compute |
| **TwentyCRM, n8n, Activepieces** | Oracle Cloud | Cloudflared | Always-on business logic |
| **Landing Page, OpenClaw UI, Admin UI** | Oracle Cloud | Cloudflared | Public-facing apps |
| **Cloudflared Tunnel** | PC1 | Single tunnel | Unified ingress (secure) |

### Data Flow
```
Borrower (SMS/Email/Call)
    ↓
Twilio/Email (external)
    ↓
Oracle Cloud (always-on)
    ├─ Activepieces (webhook receiver)
    ├─ TwentyCRM (create/update lead)
    └─ n8n (trigger workflows)
    ↓
Tailscale VPN Mesh
    ↓
Orchestrator (coordinator)
    ├─ Nexus Router (decision)
    ├─ Claude Flow (delegation)
    └─ Infisical (secrets)
    ↓
GPU Workers (inference)
    ├─ RTX 5090 (reasoning)
    ├─ RTX 3090 (analysis)
    └─ RTX 3060 (fast tasks)
    ↓
Result → TwentyCRM → Cloudflared → Public API/UI
```

## 🤖 AGENT ROLES & RESPONSIBILITIES

Project Nyra uses 8 autonomous agent roles orchestrated by Claude Flow V3. Each has specific responsibilities and success metrics:

### 1. Lead Ingestion Agent 🔍
**Responsibility**: Consume leads from all sources
- Poll LendingTree, FreeRateUpdate, LeadMailbox APIs
- Parse email inboxes (IMAP)
- Normalize data + deduplicate
- Create TwentyCRM contacts
- Trigger drip campaign workflows
**Success**: <60 sec response, 99.9% dedup accuracy

### 2. CRM Synchronization Agent 🔄
**Responsibility**: Keep TwentyCRM as system of record
- Sync lead status from all sources
- Update pipeline stages
- Merge duplicates
- Audit log all changes
**Success**: Real-time sync (<5 sec latency)

### 3. Campaign Orchestration Agent 🚀
**Responsibility**: Execute multi-channel drip campaigns
- Schedule personalized emails
- Send SMS (Twilio)
- Voicemail drops (pre-recorded)
- Detect STOP/unsubscribe
- Pause on engagement
**Success**: 25% engagement, instant STOP compliance

### 4. Quote Generation Agent 💰
**Responsibility**: Generate loan quotes
- Call Rocket Mortgage API
- Query LenderPrice wholesale rates
- Calculate payment amortization
- Email comparisons to borrowers
**Success**: <30 sec per quote, 3+ options per lead

### 5. Document Management Agent 📄
**Responsibility**: Collect & process documents
- Provide upload portal
- Send 3-day reminders
- OCR extraction (Claude Vision)
- Auto-upload to LendingPad LOS
**Success**: 100% collection, <1% OCR errors

### 6. Compliance & Audit Agent ⚖️
**Responsibility**: Enforce TCPA/TRID/Fair Lending
- Log all PII access (letta)
- Verify STOP list compliance
- Generate adverse action notices
- Monthly audit reports
**Success**: Zero violations, audit-ready

### 7. Memory & Knowledge Agent 🧠
**Responsibility**: Maintain borrower context
- Track conversation history (Letta)
- Store preferences (letta)
- Note life events
- Enable personalized messaging
**Success**: 95%+ recall accuracy

### 8. Monitoring & Health Agent 🏥
**Responsibility**: System health monitoring
- Service availability checks
- GPU worker health (Tailscale)
- API latency tracking
- Auto-restart on failure
**Success**: 99.95% uptime, <100ms alerts

## 🛠️ TROUBLESHOOTING

### Services Won't Start
```bash
# Check Docker
docker-compose ps

# View logs
make logs SERVICE=orchestrator

# Restart
make orchestrator-restart

# Full bootstrap
make clean && make bootstrap
```

### Can't Access Services
```bash
# Check port discovery
make port-discovery

# Verify tunnel is running
pgrep -f cloudflared

# Check Tailscale
tailscale status

# Test connectivity
make verify-connectivity
```

### Database Issues
```bash
# Check PostgreSQL
docker-compose logs postgres

# Backup before trying anything
make db-backup

# Reinitialize
docker-compose exec postgres psql < infra/scripts/init-databases.sql
```

### Worker Issues (GPU Inference)
```bash
# Check worker status via Tailscale
ping worker-5090.tail-net.ts.net

# Check Ollama on worker
curl http://worker-5090.tail-net.ts.net:11434/api/tags

# View worker logs (if SSH available)
ssh user@worker-5090 && docker logs ollama
```
