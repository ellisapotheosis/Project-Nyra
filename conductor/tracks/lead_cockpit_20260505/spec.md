# Specification: Lead Cockpit MVP (Timeline, Profile, Compliance Badges)

## Overview

This track aims to build the core broker cockpit for managing individual leads. It includes a detailed profile view, a unified communication timeline, and visible compliance status indicators.

## Objectives

- **Lead Profile View**: Display comprehensive lead data (name, contact, loan details, credit info).
- **Unified Timeline**: Aggregate all SMS, emails, calls, and system events for a specific lead in a chronological view.
- **Compliance Badges**: Show visual indicators for consent, DNC, STOP status, and quiet hours.
- **Campaign Controls**: Provide UI to pause, resume, or stop campaigns for the selected lead.

## Success Criteria

- Brokers can see a full history of interactions for any lead.
- Compliance status is immediately obvious upon opening a lead.
- Campaign state can be toggled directly from the cockpit.
