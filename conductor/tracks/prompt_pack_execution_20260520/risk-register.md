# Risk Register

| Risk                                                                                     | Impact                                                           | Mitigation                                                                                            |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Prompt pack contains stale paths (`apps/webapp/app`, `apps/landing/ratehunter-landing`). | Work could be applied to nonexistent or deprecated roots.        | Map every prompt target to current repo roots before editing.                                         |
| Prompt pack contains stale domain guidance (`nyra.ratehunter.net`).                      | Platform surfaces could leak back onto the public broker domain. | Keep `projectnyra.com` for platform and `ratehunter.net` only for public landing.                     |
| Prompt pack includes deprecated memory terms around Graphiti/RuVector.                   | Deprecated architecture could be revived.                        | Preserve prompt snapshots, but canonical docs and implementation must reject deprecated stack pieces. |
| Existing worktree is dirty.                                                              | New changes could overwrite or obscure user work.                | Avoid reverting; inspect touched files before editing and keep new artifacts isolated where possible. |
| External provider tasks need owner credentials.                                          | Automation could stall on MFA/dashboard/API access.              | Document owner-only tasks in `docs/OWNER_MANUAL_ACTIONS.md` and keep local implementation moving.     |
| Full prompt set spans product, infra, apps, and services.                                | A single broad pass can create low-quality churn.                | Work in phases, validate each changed surface, and record blockers explicitly.                        |
| `apps/twenty` is protected.                                                              | Direct edits could break the CRM source-of-record boundary.      | Treat `apps/twenty` as read-only reference.                                                           |
