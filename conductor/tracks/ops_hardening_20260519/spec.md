# Track Specification: Operational Hardening & Observability

## Goal

Make the platform runnable, observable, secure, and maintainable in the real world. Focus on workflow discipline, infra hardening, and observability.

## Scope

- n8n/workflow boundaries
- Infrastructure hardening (hosts, workers, compose)
- Security audits (secrets, PII)
- Observability (health checks, smoke tests)
- Documentation (handoff, manual owner actions)
