# Track: Twenty CRM Integration (System of Record)

## Overview
This track focuses on establishing Twenty CRM as the absolute source of truth for all lead and loan state in Project Nyra. This involves deploying/verifying the CRM, defining the mortgage-specific data model, setting up an MCP server for AI interaction, and wiring it to the n8n automation engine.
