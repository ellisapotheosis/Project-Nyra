# Feature map (Bonzo / AgentLegend baseline + Nyra “more”)

Baseline features found in competing systems often include:
- prebuilt multi-channel drips (SMS/email/voicemail)
- campaign templates + chaining
- lead import/sync with CRMs + lead sources
- reporting on source performance and engagement
- script libraries + personalization tokens
- mobile app + notifications

Nyra adds “more” by design:
- **policy-gated autonomy** (AI can act, but only via auditable tools)
- **multi-layer memory** (episodic + graph + CRM)
- **quote desk API** (scriptable, repeatable, versioned quote builds)
- **compliance ledger** (consent + TCPA/CAN-SPAM + audit trail)
- **human-in-the-loop** (auto escalation + approvals per action class)
- **voice-ready** (Kokoro-TTS overlay)
- **observability** (Loki/Grafana dashboards + alerting)

See `docs/COMPLIANCE_GUARDRAILS.md` for the hard boundaries.
