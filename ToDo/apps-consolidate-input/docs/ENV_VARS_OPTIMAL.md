# Environment Variables Optimal Set (Opinionated)

This file defines an **opinionated baseline** of env vars you should actually set for Nyra.

## Minimal dev
- OPENROUTER_API_KEY=...
- ANTHROPIC_API_KEY=... (if not routed via OpenRouter)
- DATABASE_URL=postgres://...
- REDIS_URL=redis://...
- FALKORDB_URL=redis://... (or falkordb://)
- JWT_SECRET=...
- NEXT_PUBLIC_API_BASE_URL=http://localhost:8000

## Production
- Same as dev plus:
- SENTRY_DSN=... (if used)
- GRAFANA_ADMIN_PASSWORD=...
- CLOUDFLARE_TUNNEL_TOKEN=...
