# Suggested integrations (Project Nyra)

## Next best adds
1) PostHog (events + funnels)
2) Sentry (errors)
3) OpenTelemetry Collector + Tempo (tracing) (optional)
4) MinIO (S3 storage)
5) Meilisearch or OpenSearch (search)
6) Firecrawl (web ingestion for RAG)
7) Composio or Nango (connector layer: Google/Microsoft/Slack/etc.)
8) Keycloak (SSO)
9) Backups: restic -> S3/Backblaze

## Coding: OpenClaw vs Claude Code / claude-flow
- OpenClaw: great at “operator” workflows (automations, inbox triage, orchestration).
- Claude Code + claude-flow: better as primary coding engine for serious refactors.
