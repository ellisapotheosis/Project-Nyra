# Project Nyra: Step-by-Step Setup by PC\n\n## Overview\n\nThis guide walks you through setting up each of your 4 PCs in order. **Start with the Orchestrator first**, then move to the workers.\n\n---\n\n## ✅ BEFORE YOU START: Prerequisites\n\n- [ ] Windows 11 on all PCs\n- [ ] Administrator access on all PCs\n- [ ] NVIDIA GPU drivers installed (check: `nvidia-smi` shows your GPU)\n- [ ] Tailscale account created (free at tailscale.com)\n- [ ] Cloudflare account with ratehunter.net domain\n- [ ] Infisical project created with initial secrets\n- [ ] Internet connection on all PCs\n\n---\n\n## Step 1: Collect PC Information (All PCs)\n\n**This is REQUIRED first - run on each PC**\n\nOpen PowerShell **as Administrator** and run:\n\n```powershell\ncd \"C:\\Users\\{username}\\OneDrive\\LANShare\\LAN-PC-Bootstrap\"\nSet-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force\n.\\scripts\\pc-info-collection\\collect-all-pcs.ps1\n```\n\n**What it does:**\n- Collects PC specs (CPU, RAM, hostname)\n- Detects GPU (nvidia-smi)\n- Gets network interfaces and MAC addresses\n- Fetches public IP (WAN)\n- Saves to: `C:\\Users\\{username}\\OneDrive\\LANShare\\PC-Inventory\\machines\\{COMPUTERNAME}.json`\n\n**Do this on all 4 PCs first.**\n\n---\n\n## Step 2: Setup Tailscale (All PCs)\n\n**Do this on each PC after collecting info**\n\n### Get Auth Key\n1. Go to https://tailscale.com/admin/settings/keys\n2. Click \"Generate auth key\"\n3. Set \"Ephemeral\" option (recommended)\n4. Copy the key (starts with `tskey-`)\n\n### Run Setup on Each PC\n\n```powershell\n$env:TAILSCALE_AUTHKEY=\"tskey-YOUR_KEY_HERE\"\n.\\scripts\\tailscale\\setup-tailscale.ps1\n```\n\n**Verify it worked:**\n```powershell\ntailscale status\n```\n\nYou should see your PC name with a Tailscale IP starting with `100.64.0.`\n\n---\n\n## Step 3: Setup Orchestrator (Start Here!)\n\n**PC: Minisforum UH680 (Ryzen 7 6800H)**\n\nRun as Administrator:\n\n```powershell\ncd \"C:\\Users\\{username}\\OneDrive\\LANShare\\LAN-PC-Bootstrap\"\nSet-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force\n.\\scripts\\orchestrator\\setup-orchestrator.ps1\n```\n\n**What it does:**\n1. Installs Docker Desktop (if not already installed)\n2. Connects to Tailscale (should get IP 100.64.0.1)\n3. Starts all orchestrator services:\n   - **MetaMCP** (12008) - MCP aggregator\n   - **Archon** (4000) - Knowledge hub\n   - **Infisical** (8080) - Secrets manager\n   - **Gitea** (3001) - Git server\n   - **Memory Stack** - Qdrant, FalkorDB, Zep, Redis\n   - **Monitoring** - Prometheus, Grafana, Loki\n   - **Workflow** - n8n, Dify\n4. Initializes services (creates Gitea admin user)\n\n**Watch the output** - it will show:\n```\nOrchestrator Setup Complete!\n\nServices are running at:\n  MetaMCP:     http://localhost:12008\n  Archon API:  http://localhost:4000\n  Infisical:   http://localhost:8080\n  Gitea:       http://localhost:3001\n  Grafana:     http://localhost:3000\n```\n\n**Verify it's working:**\n```powershell\n# Local checks\ncurl http://localhost:12008/health\ncurl http://localhost:4000/api/health\n\n# From another PC on the mesh\ncurl http://100.64.0.1:12008/health\n```\n\n**Common Issues:**\n- **\"Port already in use\"**: Change port in `docker-composes/orchestrator-complete.yml`\n- **Docker not found**: Restart PowerShell after Docker installation\n- **Services unhealthy**: Wait 60 seconds, then check `docker ps`\n\n---\n\n## Step 4: Setup Worker-3060 (Alienware M15R7)\n\n**PC: Alienware M15R7 with RTX 3060 (12GB VRAM)**\n\nRun as Administrator:\n\n```powershell\ncd \"C:\\Users\\{username}\\OneDrive\\LANShare\\LAN-PC-Bootstrap\"\nSet-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force\n.\\scripts\\workers\\setup-worker-rtx3060.ps1\n```\n\n**What it does:**\n1. Verifies NVIDIA GPU is detected\n2. Installs Docker Desktop\n3. Starts Ollama (LLM inference server)\n4. Pulls optimized models for 12GB VRAM:\n   - qwen2.5:7b-q4_K_M (6GB) ← Primary\n   - mistral:7b-q4 (6GB) ← Secondary\n   - llama3.2:3b (2GB) ← Tertiary\n   - nomic-embed-text (0.5GB) ← Embeddings\n5. Registers with orchestrator\n6. Starts monitoring (Node Exporter, DCGM Exporter)\n\n**Watch for:**\n```\nConfiguring Ollama models for RTX 3060 (12GB VRAM)...\n  Pulling qwen2.5:7b-q4... (this takes ~5-10 minutes)\n  Model ready\n```\n\n**Verify it's working:**\n```powershell\n# Local check\ncurl http://localhost:11434/api/tags\n\n# From orchestrator\ncurl http://100.64.0.11:11434/api/tags\n\n# Test inference\ncurl -X POST http://localhost:11434/api/generate -d @-\n{\"model\":\"qwen2.5:7b-q4_K_M\",\"prompt\":\"Hello\"}\n```\n\n**GPU Memory Allocation:**\n- Ollama will use shared 12GB VRAM\n- Can load 2-3 models concurrently\n- Models swap to CPU if needed (slow but works)\n\n---\n\n## Step 5: Setup Worker-3090Ti (Desktop i7-12700)\n\n**PC: Desktop with RTX 3090 Ti (24GB VRAM)**\n\nRun as Administrator:\n\n```powershell\ncd \"C:\\Users\\{username}\\OneDrive\\LANShare\\LAN-PC-Bootstrap\"\nSet-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force\n.\\scripts\\workers\\setup-worker-rtx3090ti.ps1\n```\n\n**What it does:**\n1. Verifies NVIDIA GPU (RTX 3090 Ti)\n2. Installs Docker Desktop\n3. Starts **VLLM** (8000) - Fast inference engine\n4. Starts **LMCache** (6379) - KV-cache storage\n5. Pulls recommended model:\n   - Qwen2.5-32B or Llama-3.1-70B-Q4 (16-24GB)\n6. Registers with orchestrator\n7. Starts full monitoring\n\n**Note:** Create setup-worker-rtx3090ti.ps1 if it doesn't exist (similar to 3060 but with VLLM)\n\n**Verify:**\n```powershell\ncurl http://localhost:8000/v1/models\n```\n\n---\n\n## Step 6: Setup Worker-5090 (Alienware Area-51)\n\n**PC: Alienware Area-51 with RTX 5090 (32GB VRAM)**\n\nRun as Administrator:\n\n```powershell\ncd \"C:\\Users\\{username}\\OneDrive\\LANShare\\LAN-PC-Bootstrap\"\nSet-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force\n.\\scripts\\workers\\setup-worker-rtx5090.ps1\n```\n\n**What it does:** (Same as 3090Ti but optimized for 32GB)\n1. Verifies NVIDIA GPU (RTX 5090)\n2. Installs Docker\n3. Starts VLLM with chunked prefill enabled\n4. Starts LMCache (larger 6-8GB cache)\n5. Pulls largest model:\n   - Llama-3.1-70B-Q4 or Qwen2.5-72B-Q4\n6. Registers with orchestrator\n7. Starts monitoring\n\n---\n\n## Step 7: Setup Tailscale Static IPs\n\nOnce all PCs are connected to Tailscale, assign static IPs:\n\n1. Go to https://tailscale.com/admin/machines\n2. For each PC, click \"..." and \"Edit\"\n3. Set these IPs:\n   - **Orchestrator** → 100.64.0.1\n   - **Worker-3060** → 100.64.0.11\n   - **Worker-3090Ti** → 100.64.0.12\n   - **Worker-5090** → 100.64.0.10\n\n**Save and wait 30 seconds for IPs to take effect.**\n\nVerify:\n```powershell\ntailscale status\n# Should show your PC with the assigned IP\n```\n\n---\n\n## Step 8: Setup Cloudflare Tunnels\n\n**Run on Orchestrator:**\n\n```powershell\n$env:CLOUDFLARE_TUNNEL_TOKEN=\"eyJhIjoiXXXX\"\n.\\scripts\\cloudflare\\setup-cloudflare-tunnel.ps1 -PCRole orchestrator\n```\n\n**Then on each worker:**\n\n```powershell\n.\\scripts\\cloudflare\\setup-cloudflare-tunnel.ps1 -PCRole worker-3060\n```\n\n(Repeat for worker-3090ti and worker-5090)\n\n**What this does:**\n1. Installs cloudflared\n2. Creates tunnels to ratehunter.net\n3. Sets up routes for each service:\n   - orchestrator.ratehunter.net → MetaMCP\n   - worker-3060.ratehunter.net → Ollama\n   - gitea.ratehunter.net → Gitea\n   - grafana.ratehunter.net → Grafana\n\n---\n\n## Step 9: Verify Everything Works\n\n### Local Tests (on each PC)\n```powershell\n# Orchestrator\ncurl http://100.64.0.1:12008/health\ncurl http://100.64.0.1:4000/api/health\ncurl Troubleshooting\n\n### \"nvidia-smi not found\"\n- Install NVIDIA drivers: https://www.nvidia.com/download/index.aspx\n- Verify: `nvidia-smi` should show your GPU\n\n### \"Docker not found after installation\"\n- Restart PowerShell completely\n- Docker may need Windows restart to activate\n\n### \"Tailscale auth key not working\"\n- Key may have expired\n- Generate new key at https://tailscale.com/admin/settings/keys\n- Try: `tailscale logout` then `tailscale up --auth-key=...`\n\n### \"Services not responding\"\n- Wait 60 seconds for services to start\n- Check: `docker ps` to see if containers are running\n- Check logs: `docker logs container-name`\n\n### \"Port already in use\"\n- Check what's using the port: `netstat -ano | findstr :PORT`\n- Modify port in docker-compose.yml\n- Restart containers: `docker-compose down && docker-compose up -d`\n\n### \"Can't reach other PC on Tailscale\"\n- Check firewall: Windows Defender Firewall should allow Tailscale\n- Verify static IPs assigned in Tailscale admin console\n- Try: `tailscale ping 100.64.0.1` (from worker)\n\n---\n\n## What's Next?\n\n1. **Access Grafana**: http://100.64.0.1:3000
