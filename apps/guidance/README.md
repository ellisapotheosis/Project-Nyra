## Open-Item Policy

Active guidance backlog is tracked only in the top-level guidance files,
`components/`, and `prompts/`. Frozen reference snapshots under
`apps/guidance/references/**` and dated prompt archives under
`apps/guidance/archive/**` preserve historical checklists as source material;
do not treat those archived checkboxes as current Project Nyra work unless a
current conductor track explicitly reactivates them.
