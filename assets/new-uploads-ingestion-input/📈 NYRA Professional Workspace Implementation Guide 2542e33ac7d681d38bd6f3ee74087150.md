## 📁 Database Usage Guidelines

### 🎯 NYRA Projects Master Database

**When to Use:**

- Creating new major initiatives (multi-week efforts)
- Tracking cross-functional projects
- Managing budgets and resources
- Reporting to stakeholders

**Key Properties:**

- **Status**: Planning → Active → Complete
- **Priority**: P0 (Critical) through P3 (Low)
- **Progress %**: Update weekly based on task completion
- **Tags**: Use consistent NYRA tagging strategy

### ✅ NYRA Tasks & Agent Workflows

**When to Use:**

- Daily development work (features, bugs, investigations)
- Agent-specific assignments
- Sprint planning and execution
- GitHub integration and PR tracking

**Key Properties:**

- **Agent Responsible**: Assign to specific NYRA agents
- **Story Points**: Use Fibonacci sequence (1,2,3,5,8,13)
- **Component**: Frontend, Backend, AI/ML, Multi-Agent, etc.
- **Labels**: Multiple tags for cross-cutting concerns

### 🧪 NYRA AI/ML Experiments

**When to Use:**

- Model training and optimization
- Agent performance testing
- Research hypothesis validation
- A/B testing of agent configurations

**Key Properties:**

- **Experiment ID**: Use NYRA-EXP-### format
- **Reproducible**: Always check for production experiments
- **Metrics**: Track accuracy, precision, recall, F1 scores
- **Agent Type**: Connect to specific agent development

### 📚 NYRA Technical Documentation

**When to Use:**

- Architecture decisions and specifications
- API documentation and references
- User guides and troubleshooting
- Research paper and literature management

**Key Properties:**

- **Status**: Draft → In Review → Approved → Implemented
- **Criticality**: Essential, Important, Nice-to-have
- **Review Cycle**: Set Next Review Due dates
- **Related Agents**: Tag applicable agents for context
