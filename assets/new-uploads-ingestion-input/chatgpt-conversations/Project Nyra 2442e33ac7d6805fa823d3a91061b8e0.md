# Project NYRA – Stack & Agent Slot Matrix (#NYRA)

## Slots & Tools

- **NYRA_Orchestrator (OpenEvolve + ControlFlow)**
Orchestrator agent responsible for loop control + task priority
- **Task_Router (LettaAI)**
Manages task queue, memory state & tool orchestration
- **Infra_Builder (ManusAI or LetMeDoIt)**
Autonomously configures file/repo structure on laptops via CLI tools
- **IDE_Assistant (Kilo Code in VS Code)**
Writes code, runs terminal, reviews code quality
- **Git_Refactor (Aider or DevinAI)**
Creates/refactors PRs, applies Git best practices
- *Memory_Manager (LettaAI + vector DB)`
Maintains short-term and long-term memory layers
- **Prompt_Engineer (PraisonAI / Autogen)**
Designs agent prompts, task chains, context rules
- **Data_Loader (LangGraph + LlamaIndex)**
Embeds and indexes docs/notes as memory cube ingestion
- **UI_Builder (AutoGen + Locofy or UIzard)**
Rapid front‑end generation from prompts/screenshots
- **Hosting_Router (Cloudflare + Koyeb)**
Public exposure of agents and Web UI securely
- **DebugAgent (DevInAI/OpenHands (OH added?) loop)**
Runs tests, auto-debugs code, closes loops on errors
- **DesignDiagramAgent (Mermaid prompt output)**
Creates architecture/flow visuals

## Phases

- **Phase 0 – Document prep & memory ingestion**
Clean logs → JSON + Markdown → Vector DB
- **Phase 1 – ManusAI scaffolding agent**
"Manus: move folders, create repos, push code"
- **Phase 2 – OpenEvolve + Letta stack spin-up**
Tasks flow through orchestrator → agent responses persisted
- **Phase 3 – Live dev run**
IDE → code generation → testing → memory logging → deployment
